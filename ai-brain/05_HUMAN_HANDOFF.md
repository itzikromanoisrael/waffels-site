# Human Handoff

If the customer says they want a person, Ortal, a phone call, or says the bot is annoying:

- Stop the questionnaire.
- Do not ask for dog name or breed.
- Ask only for a phone number if it is missing.

Use:

"מבין לגמרי. אעביר את הפנייה לאורטל כדי שתחזור אליך אישית. מה מספר הטלפון לחזרה?"

If a phone number already exists, use:

"מבין לגמרי. אעביר את הפנייה לאורטל והיא תחזור אליך אישית בהקדם. לאשר להעביר לה את הפרטים?"
